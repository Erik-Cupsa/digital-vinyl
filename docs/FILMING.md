# Episode two — Digital Vinyl

Use **Digital Vinyl** as the public project name. The integration instructions name
the music service so setup is reproducible; the narration can say “what's playing
on my laptop.” No script or shared document is edited by this repository.

## Before recording

- Film the factory demo before the first upload. Make and privately duplicate the
  verified original backup. Keep Pocket Eyes ready for the same board.
- Start USB-only. Confirm the screen works and the Mac detects its data connection.
- Compile/upload Digital Vinyl after backup; check WAITING, then BOOT → DEMO.
- Start the bridge, load/pair the extension and connect the music tab. In **Live**,
  verify two track changes, pause/coast, resume, tab close and reconnect.
- Repeat these on the physical board. Check RGB colors, crop, smoothness, glare,
  brightness, USB disconnect/reconnect and sustained playback before filming.
- Verify battery polarity/connector and case clearance separately before any
  portable assembly. Keep the Mac and USB tether in the explanation of live sync.

## Suggested shots

1. **Reveal:** round record with the album art turning in its center.
2. **Proof:** show the selected music tab and board together; pause, watch it coast,
   then play and change tracks. This is the real integration shot.
3. **Build:** briefly show the integrated board, USB connection and code upload.
4. **Rehearsal alternative:** use the original generated covers to practice focus,
   framing and the reveal. Keep DEMO visible; do not imply those covers are live.
5. **Recovery:** demonstrate returning to Pocket Eyes or the factory demo only
   after you have actually tested the corresponding upload/restore.

The desktop preview supports clean view with **F**, **Esc** to return, and explicit
rehearsal controls. Its screenshot is synthetic original artwork. The physical
board uses BOOT to toggle live/rehearsal; browser demo buttons do not control it.

## Claims supported by the implementation

- “It displays the artwork for the track playing in my selected browser tab.”
- “It spins when playback runs and coasts when I pause.”
- “The computer sends a tiny cover image and playback state over USB.”

Use those as demonstrated behavior only after the first live device check. Do not
claim the board streams music, plays audio, syncs from a phone, is wireless, has a
measured battery life, fits the pouch, or has tested factory recovery yet. A battery
alone does not remove the laptop/data dependency. Use music/art you have rights to
include in a published recording; the bundled rehearsal art is original MIT content.
